# Bilan Lounge

A responsive restaurant landing page built with HTML, CSS, and JavaScript.

## Overview

This project is a static web page for a food service brand called **Bilan Lounge**. It includes:

- A fixed header with navigation links
- A hero slider using Swiper.js
- Dishes and menu sections with product cards
- An about section with service highlights
- Search form toggle and mobile navigation controls
- Styled layout with custom CSS and Font Awesome icons

## Files

- `index.html` - main page markup
- `style.css` - custom styles for layout and design
- `main.js` - interactive behavior for menu toggle, scrolling navigation, search form, and Swiper sliders
- `images/` - image assets used throughout the site

## Dependencies

The page uses the following CDN libraries:

- Swiper.js for the image slider
- Font Awesome for icons

## Usage

1. Clone or download the repository.
2. Open `index.html` in your browser.

> Tip: For best results, serve the files from a local web server (e.g. VS Code Live Server) to avoid any browser restrictions when loading static assets.

## Deployment

This project can be deployed as a static site using GitHub Pages, Netlify, or any static hosting provider.

## Notes

- The page is designed as a landing site and does not include backend ordering functionality.
- Images are stored locally in the `images/` folder.
